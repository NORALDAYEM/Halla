# تشغيل هلاا
من مجلد server شغّل `npm install` ثم `npm start` باستخدام Node.js 22.13 أو أحدث. افتح التطبيق على المنفذ PORT (الافتراضي 3000). يعمل الموقع والخدمة على نفس النطاق. استخدم HTTPS على الجوال.
 
- للحسابات اضبط SUPABASE_URL وSUPABASE_PUBLISHABLE_KEY. فعّل حسابات البريد وتأكيد العنوان ومزوّد SMTP في مشروع Supabase، وأضف رابط التطبيق إلى قائمة روابط إعادة التوجيه. افتح رابط الاستعادة في المتصفح نفسه الذي أرسل الطلب.
- للصوت اضبط LIVEKIT_URL (wss) وLIVEKIT_API_KEY وLIVEKIT_API_SECRET على الخادم. استخدم خادم LiveKit أو مشروعك المستضاف. تُمنح صلاحية النشر للميكروفون فقط. يبدأ المستمع بلا إذن نشر الصوت.
- عيّن halaa_admin في app_metadata من إدارة موثوقة لتفويض إدارة الإعلانات وكل الغرف. للغرف الافتراضية، تدعم خريطة halaa_rooms في app_metadata أدوار owner وmoderator وspeaker وlistener لكل معرّف. مالك الغرفة المنشأة من التطبيق يُحفظ تلقائيًا. يمكن للمشرف منح المتحدث الميكروفون وإعادته للاستماع.
- HALAA_DB مسار قاعدة SQLite على قرص دائم. تحفظ الغرف والأدوار الممنوحة والإعلان. تستخدم هذه النسخة مثيل خدمة واحدًا. HALAA_ROOM_IDS قائمة JSON اختيارية للغرف الأساسية.
- معاينة HTML المستقلة تعرض التصميم والتفاعلات المحلية والإعلانات المحفوظة في المتصفح. أزرار الحساب والصوت المباشر توضّح حالة الاتصال. ميزات المتجر والعملات الحالية تجريبية.
