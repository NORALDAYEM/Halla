# هلاا — Halaa

مشروع Flutter لتطبيق هلاا ولوحة الإدارة. هذه نسخة تطوير أولية وليست منتجاً مكتملًا.

## التشغيل

```bash
flutter create --platforms=android,ios .
flutter pub get
flutter run -t lib/main.dart
```

لتشغيل الإدارة: `flutter run -t lib/admin_main.dart`.

لا توجد حتى الآن خدمات صوت مباشرة أو مدفوعات حقيقية. لا تضع أسرار الدخول في المستودع.
